Orders from this device

Orders placed from this browser are listed here so the counter can track them. (A static website cannot collect orders from other customers' phones — those arrive on the store's WhatsApp as usual.)

Store settings

The WhatsApp number is used by every order button on the site. Use the full number with country code, digits only (e.g. 923433009226).

Catalog data

Export downloads the full product list as a JSON file (your backup, or the file to make changes permanent in the site code). Import replaces the current list with a JSON file. Reset removes all admin changes and brings back the original 30 demo products.

Note: this admin panel works without a server, so its changes are stored in this browser only (localStorage). Anyone with the password on this device can manage the catalog here. For a multi-user/permanent setup, the exported JSON is merged into the site files.
